# Dependency overrides needed to install ALL extras together in CI.
#
# dagster-dbt and acryl-datahub disagree about sqlglot:
#
#   dagster-dbt>=0.28.18            requires  sqlglot[rs]<28.1.0
#   acryl-datahub[sql-parser]       requires  sqlglot==30.12.0
#
# so `pip install edgy-dag-tools[all]` is genuinely unsatisfiable as
# published. The two are only ever needed in the same environment for
# TESTING -- a deployment installs the extras it actually uses -- so
# rather than dropping one from `[all]`, CI overrides sqlglot to the
# newer pin and installs both.
#
# This is not wishful thinking: the development environment has run this
# exact combination (dagster-dbt 0.29.1 + acryl-datahub 1.6.0.17 on
# sqlglot 30.12.0) with the full suite green, so dagster-dbt's upper
# bound is conservative rather than load-bearing for anything dag-tools
# touches. sqlglot does emit a deprecation warning about the `rs`
# extra under 30.x, which is visible in the test output and harmless.
#
# Revisit when dagster-dbt widens its bound; at that point this file
# should be deleted rather than updated.
sqlglot==30.12.0
